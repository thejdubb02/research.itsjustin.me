# research.itsjustin.me

GitHub Pages source for [research.itsjustin.me](https://research.itsjustin.me), the security-research and open-source page of Justin Willhite (thejdubb02): full-stack engineer and independent security researcher.

The page lists white-box source review and the fixes merged upstream into open-source projects, with links to each pull request and advisory.

## Do not hand-edit index.html

`index.html` is generated. An external script rebuilds it from the current list of merged pull requests and writes it back to this repo, so any manual edit to the page will be overwritten on the next run. Change the generator, not the file.

Everything else in the repo (`CNAME`, `logo.svg`, `avatar.png`, the favicons) is a static asset the page references, and is safe to edit by hand.

## Hosting

Served by GitHub Pages at the custom domain in `CNAME` (`research.itsjustin.me`). Static, no trackers.
